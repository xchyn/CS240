Exercise set 7 · after the universality lecture NAND and NOR

One gate is all you need

The NAND and NOR gates; the proof that either one alone can build every circuit there is; the bubble notation and De Morgan's alternate symbols; and the mechanical conversion of an AND–OR circuit into pure NAND.

Every circuit so far has been drawn in AND, OR and NOT, and Set 5 proved that those three suffice for any truth table at all. Real chips are not built that way. They are built out of one gate type repeated billions of times, and this set is about why that is possible and how to get there from the circuits you already know how to draw.

The claim is strong enough to be worth stating plainly: any combinational circuit whatsoever can be built out of NAND gates alone. Not most circuits, not with some special exceptions — all of them. The same is true of NOR. Nothing else in this course is quite so surprising on first hearing and quite so easy to prove once you see how.

7.1Two more gates

Both gates are an old gate with an inversion bolted on the output, and both symbols say exactly that: the familiar shape, plus the little circle that has meant "invert" since Set 3.

NAND — (AB)′
AND, then invert. 0 only when both inputs are 1.

NOR — (A + B)′
OR, then invert. 1 only when both inputs are 0.

Each is the exact complement of the gate it is named after — the NAND column is the AND column upside down, and the NOR column is the OR column upside down. Read them in words and each has a crisp description of its own: NAND is 0 only when everything is 1; NOR is 1 only when everything is 0.

Where the circle sits

NAND is AND followed by NOT. It is not NOT followed by AND, which would be A′B′, a different function — the trap from Exercise 3.12 wearing a new hat. The circle is on the output side of the body, and that is what tells you the order.

A shorthand for these two gates

Each of these gates has an operator symbol of its own, and this page uses them wherever writing out the brackets would bury the point being made:

A ↑ B  means  NAND(A, B) = (AB)′
A ↓ B  means  NOR(A, B) = (A + B)′

The up arrow is read aloud as "nand" — "A nand B" — and it is an operator, like + and ·, rather than a new gate. From the table above, 1 ↑ 1 = 0 and 1 ↑ 0 = 1. Its own name is the Sheffer stroke, which you will meet in a logic course and can forget here.

An expression built from it is read left to right as a chain of gates: (A ↑ B) ↑ C means "NAND A with B, then NAND that result with C", which is one gate feeding another. The brackets are doing real work — unlike + and ·, this operator is not associative, so A ↑ (B ↑ C) is a different circuit computing a different function. Exercise 7.4 is precisely that point, and until you have done it, write the brackets every time.

7.2Why one gate is enough

The argument has two steps, and neither is hard.

Step one is Set 5. Every truth table can be written as a sum of products, and a sum of products is built from AND, OR and NOT. So those three gate types can build any combinational circuit.

Step two is to build each of those three out of NAND gates alone. If NAND can make a NOT, an AND and an OR, then NAND can make anything those three could make — which, by step one, is everything. Replace each gate of an AND–OR–NOT circuit with its NAND equivalent and you have a pure-NAND circuit computing the same function.

A set of gates that can build every function is called functionally complete, or universal. {AND, OR, NOT} is functionally complete; step two shows {NAND} is too, all by itself.

The same argument, twice

Everything here has a NOR version obtained by swapping AND with OR and 0 with 1 — the duality from Set 4. NOR is universal for exactly the same reason, and the three NOR constructions are the three NAND ones with the gates exchanged. Learn one set properly and the other costs nothing.

7.3The NAND toolkit

Three small circuits, worth being able to draw from memory.

NOT. Tie both inputs of a NAND together. Then the gate computes (A · A)′, and A · A = A by idempotence, so the output is A′.

AND. A NAND gate is an AND with an unwanted inversion on the end, so undo it with the NOT you have just built. Two gates.

OR. This is the one that needs De Morgan. Invert both inputs first, then NAND them:

(A′ · B′)′ = (A′)′ + (B′)′ = A + B

so three gates — two acting as inverters, one doing the work.

The NOR toolkit is the mirror image: NOR(A, A) is NOT; a NOR followed by that inverter is OR; and inverting both inputs before a NOR gives AND. Exercise 7.3 asks you to draw all three and check them.

7.4Bubbles and alternate symbols

De Morgan's laws have a picture. Since (AB)′ = A′ + B′, a NAND gate — an AND with a bubble on its output — computes the same function as an OR gate with bubbles on its inputs:

NAND
AND, bubble on the output.

the same gate
OR, bubbles on the inputs.

Both symbols denote one physical gate; which you draw is a matter of what you want the reader to notice. And the same holds for NOR, which may be drawn as an AND gate with bubbles on its inputs.

The reason this matters is the rule it licenses:

two bubbles on the same wire cancel

because inverting twice does nothing. That single fact turns circuit conversion into a drawing exercise: add bubbles in pairs wherever you like, slide them along wires, and cancel them when they meet. Adding a pair changes nothing; cancelling a pair changes nothing; and in between, the gates have quietly turned into NANDs.

7.5Converting a circuit

An SOP circuit is a layer of ANDs feeding an OR. To make it pure NAND:

  1. Put a bubble on the output of every AND gate, turning them into NAND gates.
  2. Put a bubble on each input of the OR gate, to cancel the ones you just added.
  3. The OR gate with bubbled inputs is a NAND gate, by §7.4. Redraw it as one.
  4. Any input that arrives complemented needs its own inverter, which is a NAND with its inputs tied together.
Worked example

F = AB + CD, first in the form Set 5 would give you:

Bubble both AND outputs and both OR inputs — four bubbles, added in cancelling pairs, so the function is unchanged. The ANDs are now NANDs, and the bubbled-input OR is a NAND:

Three gates before, three gates after. That is the general result and it is the reason the technique is worth knowing: converting a two-level AND–OR circuit to NAND costs nothing at all. One NAND per product term, plus one to collect them.

The algebra confirms it in one line, using De Morgan on the double complement:

AB + CD = ((AB)′ · (CD)′)′ = NAND(NAND(A, B), NAND(C, D))

The same manipulation with sums and products exchanged converts a two-level OR–AND circuit into pure NOR at the same price, which is Exercise 7.10.

7.6Reference

built from NANDfrom NOR
A′ = NAND(A, A)A′ = NOR(A, A)
AB = NAND(NAND(A,B), NAND(A,B)) AB = NOR(NOR(A,A), NOR(B,B))
A + B = NAND(NAND(A,A), NAND(B,B)) A + B = NOR(NOR(A,B), NOR(A,B))
  • NAND = AND then invert, NOR = OR then invert. The bubble is on the output.
  • Alternate symbols. NAND = OR with inverted inputs; NOR = AND with inverted inputs. Both are De Morgan drawn rather than written.
  • Double bubbles cancel on any wire.
  • Two-level SOP to NAND is free: k product terms become k + 1 NAND gates, plus one NAND per complemented input.
  • Notation. A ↑ B is NAND(A, B) and A ↓ B is NOR(A, B).
  • Neither gate is associative, so a chain of two-input NANDs is not a multi-input NAND, and the brackets in an arrow expression cannot be dropped. Exercises 7.4 and 7.5.

7.7Exercises

Where a question says "pure NAND", every gate in your answer must be a NAND gate, inverters included. Count the gates when you are done; that number is the point of most of these.

The gates and their toolkits

Give the truth tables of NAND and NOR side by side with AND and OR. Then answer: is NAND the same as A′ · B′? Is NOR?

Each new column is the complement of the one to its left, row by row.

NAND is not A′B′. NAND is (AB)′ = A′ + B′ by De Morgan — a sum. One row settles it: at A = 1, B = 0, NAND gives (1·0)′ = 1 while A′B′ gives 0·1 = 0.

NOR, on the other hand, is exactly A′B′, again by De Morgan: (A + B)′ = A′B′. Check the table — the NOR column is 1 only in the row where both inputs are 0, which is precisely when both complements are 1.

So of the two tempting identifications, one is wrong and the other is right, and guessing gets you a 50% score. The reliable move is to apply De Morgan rather than read the gate name: push the complement inward and the gate flips.

Using NAND gates only, build NOT, AND and OR. Give the gate count for each, and verify the OR construction with a truth table.

NOT — one gate. Tie the inputs together: (A·A)′ = A′, since A·A = A.

AND — two gates. NAND the inputs, then invert the result with a second NAND wired as a NOT: ((AB)′)′ = AB.

OR — three gates. Invert each input, then NAND the two results.

The algebra is one application of De Morgan: (A′ · B′)′ = (A′)′ + (B′)′ = A + B. The pattern is worth naming: to get an OR out of an AND-like gate, invert what goes in and what comes out.

Note the asymmetry in the counts — 1, 2, 3. An AND is cheap in NAND and an OR is expensive, which is exactly backwards for NOR and is one reason a designer might prefer one gate family over the other for a particular circuit.

Now do it with NOR gates only: build NOT, OR and AND, and give the gate counts. What is the pattern relating these three circuits to the NAND ones?

NOT — one gate. (A + A)′ = A′, since A + A = A.

OR — two gates. A NOR followed by an inverter undoes the unwanted complement: ((A + B)′)′ = A + B.

AND — three gates. Invert both inputs, then NOR them: (A′ + B′)′ = AB.

The pattern. Each circuit is its NAND counterpart with every gate replaced by a NOR and the roles of AND and OR exchanged. That is the duality principle from Set 4 showing up as a fact about drawings: swap AND with OR, and 0 with 1, and a true statement stays true.

The counts swap too — 1, 2, 3 for NOT, OR, AND, where NAND gave 1, 2, 3 for NOT, AND, OR. A circuit that is mostly ORs is cheaper in NOR; one that is mostly ANDs is cheaper in NAND.

The algebra of NAND

Is NAND associative? That is, does (A ↑ B) ↑ C always equal A ↑ (B ↑ C)? Tabulate both. (Recall that A ↑ B is shorthand for NAND(A, B), so the first expression is a NAND gate feeding a second one.)

No. The two columns differ in four of the eight rows — for instance at A = 1, B = 1, C = 0, where (1 ↑ 1) ↑ 0 = 0 ↑ 0 = 1 and 1 ↑ (1 ↑ 0) = 1 ↑ 1 = 0.

This is a real difference from AND, OR and XOR, all three of which are associative and can therefore be chained without brackets. With NAND the brackets are part of the meaning, and a drawing that leaves the grouping ambiguous is a drawing of nothing in particular.

The underlying reason is the inversion. AND is associative, but NAND inverts after every operation, and an odd number of extra inversions lands in a different place depending on where the brackets are.

NAND is commutative — A ↑ B = B ↑ A, since AB = BA and complementing preserves equality — so the order of the two inputs to one gate never matters. It is only the grouping of several gates that does.

A three-input NAND gate outputs (ABC)′. Does chaining two-input NANDs — (A ↑ B) ↑ C — give the same thing? If not, what does the chain compute, and how would you build a genuine three-input NAND from two-input gates?

No. The two columns agree in only four of the eight rows, and disagree everywhere else — including every row where C = 1.

What the chain computes, worked out algebraically:

(A ↑ B) ↑ C = ((AB)′ · C)′ = (AB)′′ + C′ = AB + C′

which is nothing like (ABC)′ = A′ + B′ + C′.

Building a real three-input NAND. Work out what you want — AND the three inputs, then invert once. Chain two NANDs to get (AB)′, invert it back to AB with a third, NAND that with C to get (ABC)′. Three gates: NAND(NAND(NAND(A,B), NAND(A,B)), C).

The lesson generalises past this gate. Chaining works for associative operations and silently produces a different function for the others, so before you extend any two-input gate into a chain, check that the operation is associative. AND, OR and XOR pass; NAND and NOR do not.

Build a NAND gate out of NOR gates only, and a NOR gate out of NAND gates only. How many gates does each take, and what does the result prove?

NAND from NOR — four gates. Build AB from three NORs as in Exercise 7.3, then invert with a fourth:

(AB)′ where AB = NOR(NOR(A,A), NOR(B,B))

so NAND(A, B) = NOR(t, t) with t = NOR(NOR(A,A), NOR(B,B)). Two inverters, one NOR to combine, one more to invert the result.

NOR from NAND — four gates, by the mirror-image argument: build A + B from three NANDs, then invert with a fourth.

What it proves. Either gate can simulate the other, so the two universality claims are really one claim. Once you know NAND is universal, NOR must be: build every NAND you need out of NORs and the job is done.

It also shows the cost of insisting on the wrong family. A circuit needing n NAND gates can always be built with 4n NOR gates, and usually far fewer — four is the crude upper bound you get by translating gate by gate without looking for cancellations. Converting a whole circuit properly, as in §7.5, is much cheaper than converting each gate in isolation.

Draw a NAND gate in its alternate form, and a NOR gate in its alternate form. State which law each drawing expresses, and use one of them to explain why two bubbles on a wire cancel.

NAND is an AND with an output bubble, and equally an OR with input bubbles:

(AB)′

A′ + B′

which is the law (AB)′ = A′ + B′.

NOR is an OR with an output bubble, and equally an AND with input bubbles:

(A + B)′

A′B′

which is (A + B)′ = A′B′. Both drawings are De Morgan's laws with the algebra taken out.

Why bubbles cancel. A bubble is an inverter, and (X′)′ = X by the involution law. So a wire carrying two bubbles — one from the gate that drives it, one on the input it feeds — carries the signal unchanged, and both may be erased.

That is what makes the conversion in §7.5 legitimate rather than a trick. You are allowed to add a pair of bubbles anywhere, because a pair does nothing; and once they are there, each can be absorbed into the gate beside it by redrawing that gate in its alternate form.

Conversion

Convert F = AB + CD into a pure NAND circuit. How many gates does each version use?

The AND–OR version, three gates:

Bubble the two AND outputs and the two OR inputs. The bubbles cancel in pairs, so the function is untouched; the ANDs become NANDs and the OR, now drawn with input bubbles, is a NAND as well:

Three gates either way. Two-level AND–OR to NAND is free — a fact worth internalising, because it means the K-map minimisation of Set 6 is also the right thing to do when your target technology is NAND. Minimise as SOP, then translate.

Checking it algebraically:

NAND(NAND(A,B), NAND(C,D)) = ((AB)′ · (CD)′)′ = (AB)′′ + (CD)′′ = AB + CD

The middle step is De Morgan and the last is involution. Every conversion in this set is that same pair of moves.

Convert F = AB′ + BC into a pure NAND circuit. Count the gates and say where the extra one came from.

Four gates. Three of them are the two-level conversion from Exercise 7.8 — one NAND per product term and one to collect them. The fourth is an inverter for B′, built as a NAND with its inputs tied together.

That is the general rule: a k-term SOP needs k + 1 NAND gates, plus one more for every input that appears complemented. Here k = 2 and one literal is complemented, giving 2 + 1 + 1 = 4.

Note that B itself is used twice — once through the inverter and once directly into the second NAND — so the B input fans out, and the dot on the drawing is doing real work.

A practical consequence: complemented literals are not free in NAND logic, so a minimisation that removes a complemented variable is worth more than one that removes a plain one. It is a small thing, and it is the kind of small thing that decides between two K-map covers of equal literal count.

Convert F = (A + B)(C + D) into a pure NOR circuit, and justify it algebraically.

Three NOR gates, exactly mirroring Exercise 7.8. Bubble the two OR outputs and the two AND inputs; the ORs become NORs, and the AND with bubbled inputs is a NOR.

The algebra, which is Exercise 7.8's with AND and OR exchanged throughout:

NOR(NOR(A,B), NOR(C,D)) = ((A+B)′ + (C+D)′)′ = (A+B)′′ · (C+D)′′ = (A + B)(C + D)

So a two-level OR–AND circuit converts to pure NOR for free, just as AND–OR converts to pure NAND for free. Which pairing you get depends on whether you minimised into SOP or POS form, and that choice — made back on the K-map — is what decides which gate family your circuit wants.

The symmetry is complete and worth stating once: SOP goes with NAND, POS goes with NOR. Mixing them up produces a working circuit with unnecessary inverters scattered through it.

Building and reading

Why it works, algebraically. t = (AB)′, so

A ↑ t = (A(AB)′)′ = (A(A′+B′))′ = (AB′)′

using A·A′ = 0, and symmetrically B ↑ t = (A′B)′. NANDing those two gives AB′ + A′B, which is Exercise 4.1's expression for XOR.

which is the same function in three literals rather than four. As a circuit that is an OR and an AND — but in NAND terms the factored form is not obviously cheaper, since it is a product of sums and NAND suits sums of products. That is a useful caution about minimisation. "Fewer literals" is a good proxy for "cheaper circuit" only while the target is two-level AND–OR. Once the target is a specific gate family, the count that matters is the count of gates in that family, and it does not always move in the same direction.

Cost and reasoning

A function has been minimised to a four-term SOP in which three distinct variables appear complemented. How many NAND gates does the pure-NAND implementation need? State the general rule and where it fails.

Four product terms need four NAND gates, one collecting NAND, and one inverter per complemented variable:

4 + 1 + 3 = 8 gates

The general rule. A k-term SOP over a set of inputs of which c appear complemented somewhere needs k + 1 + c NAND gates. Note that c counts distinct variables, not occurrences: a variable that appears complemented in three different terms still needs only one inverter, whose output fans out.

Where it fails. Three places, all worth knowing.

  • A single-term SOP. With k = 1 there is nothing to collect, and the second NAND is used as a plain inverter rather than as an OR. The formula still gives the right number, but for a different reason than you think.
  • Shared sub-expressions. If two terms have a common part, computing it once can beat the formula — which is exactly how Exercise 7.11 built XOR in four gates rather than five.
  • Fan-in limits. The formula assumes gates can have as many inputs as the terms are long. Real parts come in two-, three- and four-input versions, and a five-literal term has to be split across several gates, adding to the count.

The rule is still the right first estimate, and its main use is comparative: given two minimal covers from a K-map with the same literal count, the one with fewer distinct complemented variables is the cheaper circuit.

Why do real chips favour NAND over AND? Answer in terms of what a gate is physically made of, and say what this means for how you should count cost.

In CMOS, the technology essentially all digital chips are built in, a gate is made of transistors in two complementary networks, and the natural output of that arrangement is inverting. A two-input NAND is four transistors; so is a two-input NOR. A two-input AND is a NAND followed by an inverter — six transistors — and an OR is likewise six.

So the inverting gates are not merely as cheap as the non-inverting ones, they are strictly cheaper, and the AND gate you draw is physically a NAND with an apology on the end. Building from NAND is not a clever economy; it is what the silicon was going to do anyway.

There is a speed argument too. The extra inverter in an AND gate is an extra stage of delay on every signal passing through, so a circuit expressed in NANDs is not just smaller but faster than the same circuit in ANDs and ORs.

What it means for counting. The gate counts used in this course are a convenient fiction. A fairer measure is transistor count, or gate inputs, and by that measure the AND–OR circuit you started with was never as cheap as it looked. This is also why the conversion of §7.5 being "free" understates the case: converting a three-gate AND–OR circuit to three NANDs removes two inverters that were there all along, hidden inside the symbols.

The other half of the answer is manufacturing. A chip built from one repeated cell is easier to lay out, verify and yield than one built from a zoo of different cells, which is why a standard-cell library is dominated by a few gate types with NAND and NOR at the centre of it.

Challenge. There are sixteen different two-input Boolean functions. Exactly two of them are universal on their own. Show that NAND and NOR are the only candidates.

Write a two-input function as the four values it takes, in the order f(0,0), f(0,1), f(1,0), f(1,1). There are 24 = 16 such patterns, which is where the sixteen comes from.

First requirement: f(0,0) must be 1. Suppose not — suppose f(0,0) = 0. Feed 0 into every input of a circuit built entirely from copies of f. The first gate sees 0, 0 and outputs 0; so does every gate after it, by the same argument, all the way to the output. So the circuit outputs 0 whenever all its inputs are 0, and it can never compute A′ — which must be 1 when A is 0 — nor the constant 1. Such an f is not universal. (This is Exercise 3.15's argument, reused.)

Second requirement: f(1,1) must be 0, by the mirror image of that argument with every input set to 1.

That leaves the two middle values free, so exactly four functions survive:

f(0,0)f(0,1)f(1,0)f(1,1)function
1000NOR
1010B′
1100A′
1110NAND

Eliminating the two middle ones. The function A′ ignores its second input entirely. Any circuit built from copies of it is a chain of inverters, so its output depends on exactly one input and is either that input or its complement. It cannot compute AB, which depends on two. The same argument kills B′.

What remains is NAND and NOR, and §7.2 showed both actually are universal — the argument above only showed that nothing else can be. Two necessary conditions narrowed sixteen candidates to four, an independent argument removed two more, and a construction confirmed the last two.

The general result

The full classification of which sets of Boolean functions are functionally complete is Post's theorem, and it says a set fails to be complete exactly when all of its members share one of five properties: preserving 0, preserving 1, being self-dual, being monotone, or being affine. The two conditions used above are the first two of those five. It is a satisfying piece of mathematics and the two-input case, which you have just done in full, is the whole idea in miniature.

Where this goes next

The combinational half of the course closes here: from a specification to a truth table, to a minimal expression, to a two-level circuit, to a pure-NAND implementation that a fabrication process could actually build. What is missing is memory — every circuit so far forgets everything the instant its inputs change. Adding a feedback path to gates you already understand produces a device that remembers, and that is where the second half begins.

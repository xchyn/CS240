1. Program structure, registers, and I/O

Read assembly as changes to registers, memory, and the next instruction. The ALU computes on register values; loads and stores copy data between registers and RAM. Keep pseudo-instructions enabled, delayed branching OFF, and assemble one complete program at a time.

Syntax or stateRule to remember
.text / .dataExecutable instructions / declared data; directives act during assembly.
name: / # commentA label names a location. Outside quoted strings, # begins a comment.
.globl mainExports the entry label; it neither runs main nor allocates a variable.
li / la / moveCopy a constant / label’s address / register value into a register.
.include "file.asm"Assemble another source file too; the file must exist. Helper labels such as PrintString are not built-in instructions.
Registers and PC32 general-purpose 32-bit registers; PC tracks execution. PC, HI, and LO are separate from those 32 registers.
$zero; $t0–$t9; $s0–$s7Constant zero; temporary work; saved values subject to the call contract.
$a0–$a3; $v0–$v1; $ra; $spArguments; results/service selector; return address; stack pointer.
Other register aliasesLeave $at for assembler expansions and $k0/$k1 for kernel use; $gp and $fp are global/frame-pointer conventions.
MARS service in $v0Arguments / result
1 / 4 / 11Print integer in $a0 / NUL-terminated string at $a0 / character code in $a0.
5Read integer; the result replaces $v0. Keep it before selecting another service.
8$a0=buffer address, $a1=capacity; writes input and NUL within that capacity.
9Request $a0 bytes; returned block address replaces $v0. Keep the address before another service.
12Read one character; its code is returned in $v0.
10Exit. Put it before a function body to prevent main from falling into that body.

Floating-point input and output

2, 3, 6, and 7 are four separate service numbers. Put the chosen number in $v0, then execute syscall.

Service in $v0OperationWhere the value goes
2Print a floatSupply the value in $f12.
3Print a doubleSupply one double in the pair $f12/$f13.
6Read a floatThe input value is returned in $f0.
7Read a doubleThe input value is returned in the pair $f0/$f1.

A float uses 32 bits; a double uses 64 bits and offers greater precision. The $f registers belong to the floating-point register set. Each holds 32 bits, so a double occupies two registers together.

Worked example — read a float, then print it back: entering 3.5 makes this fragment print 3.5.

li $v0,6           # Select read-float service
syscall            # Input goes into $f0
mov.s $f12,$f0     # Copy the float to the print argument
li $v0,2           # Select print-float service
syscall            # Print the value in $f12

mov.s copies one single-precision float. For a double, use service 7, then mov.d $f12,$f0 to copy both registers, then service 3 to print. These moves copy a value; they do not convert between float and double. Optional floating-point arithmetic example.

A service number is a MARS convention, not an instruction opcode. Assemble and step; input/output example; storage-location preview.

2. Arithmetic, bits, and HI/LO

Most arithmetic uses operation destination, source1, source2; sources are read before the destination is replaced. A register contains bits, so signedness comes from the instruction and the intended interpretation. Choose input bounds that keep every intermediate result valid.

OperationMeaning or limit
add, sub; addiSigned addition/subtraction; overflow raises an exception. addi uses a signed 16-bit immediate.
addu, subu, addiuKeep the low 32 bits without a signed-overflow exception. addiu still sign-extends its immediate.
Two’s-complement subtraction24−48 = −24; 73−45 = 28. Signed 32-bit range: −2³¹ through 2³¹−1.
mult; mfhi; mfloSigned 64-bit product goes to HI:LO; copy either half into a general-purpose register. Use LO alone when the full signed result fits a signed 32-bit integer; otherwise keep both halves.
mul rd,rs,rtKeep a 32-bit product in rd; use in-range operands when that is the intended full result.
div rs,rt; remSigned quotient in LO, remainder in HI; quotient truncates toward zero. rem is convenient remainder syntax.
Division boundsExclude divisor zero and −2³¹ ÷ −1; copy needed HI/LO results before another multiply/divide.
abs d,sPseudo-instruction for absolute value. Exclude −2³¹, whose positive magnitude cannot fit in signed 32 bits.
and, or, xor, nor, notBitwise AND, OR, XOR, complemented OR, and complement; not is a pseudo-instruction.
andi, ori, xoriTheir 16-bit immediate masks are zero-extended. andi r,x,1 extracts the low bit.
sll, srl, sraLeft zero fill; right zero fill; right sign fill. Lost bits are discarded; sra on a negative odd value differs from signed division by 2.

Multiplication; division; optional details: R-format encoding and I-format encoding. A basic instruction occupies four bytes; a pseudo-instruction may expand into several basic instructions.

3. Comparisons, branches, and jumps
A comparison can produce a 0/1 flag; a branch chooses the next instruction. An if/else needs a jump past the other arm. Translate the condition literally, then test its boundaries—including zero.
Syntax / patternMeaning
slt d,a,b / slti d,a,kSet d to 1 when signed a<b or a<k; otherwise 0. They do not jump.
sltu d,a,bUnsigned less-than comparison; useful for ordered pointer addresses.
sgt / sle / sne / seq / sgePseudo comparisons: > / ≤ / ≠ / = / ≥; produce a 0/1 flag.
beq a,b,L / bne a,b,LJump to L if equal / unequal; otherwise continue with the next instruction.
beqz / bnezPseudo tests for zero / nonzero. MARS also accepts immediate comparison variants.
blt / ble / bgt / bgePseudo branches for signed < / ≤ / > / ≥.
j L / b L / nopUnconditional jump / unconditional branch pseudo / no operation; neither j nor b records a return link.
AND / OR / NOTAND rejects on any failure; OR accepts on any success; NOT reverses the condition.
switch with breakTest case values using equality branches; choose default if none matches. Jump to a common exit after each selected body.
Parity and signEven means remainder zero (or low bit zero). Nonpositive includes zero; it does not mean negative.
If/else; compound conditions; branch target calculation. A basic branch uses target = PC+4 + 4×signed_offset; the offset counts instruction words. Our no-delay setting executes the selected next instruction immediately.

4. Counter loops, sentinel loops, and nested loops
Write initialization, test, body, update, and the backward jump. Keep inclusive i<=N separate from exclusive i<N. Every continuing path must reach progress; initialize each inner counter and per-item product again when the outer loop begins another item.
Loop or exampleTranslation checkpoint
for / while / do-whileA top test can run the body zero times; do-while tests after the body and runs it at least once.
Sentinel inputRead new input on the continuing path; test the sentinel before adding or processing it.
Sum below N / sum of squaresChoose the exact bounds; start an additive total at 0.
Σ iⁱReset term=1 and its inner counter for each i; add the term once. C++ ^ means XOR, not exponentiation.
Nᴺ + N!Start both products at 1; multiply power by fixed N and factorial by changing i.
Divisibility / final digitRemainder zero means divisible; for positive i, remainder 6 modulo 10 means ends in 6.
OR and AND filtersA shared print block prevents duplicates for OR; AND rejects as soon as one requirement fails.
Alternating squaresAdd an odd-index square, subtract an even-index square; update the counter on both paths.
Pythagorean triplesThree counters enumerate positive ordered triples; reset inner counters and test a²+b²=c².
Sentinel example; do-while; nested products; power plus factorial; filters; triples. Check zero/one iterations, the last valid index, and safe intermediate arithmetic.

5. Declarations, arrays, and strings
An address identifies a byte location; a load copies its contents. Registers are not RAM. Static declarations, heap blocks, and the stack occupy different regions of the program’s address space; 32-bit byte addresses name at most 2³² locations, not necessarily installed physical RAM.
Syntax / ruleQuick reference
.word / .byte / .space NInitialize four-byte values / one-byte values / reserve N bytes. Reservation is not meaningful initialization.
.asciiz / .align 2Store quoted bytes plus NUL / place the next item at a multiple of 2²=4. Alignment may insert padding.
Quotes, escapes, and listsCommas separate values. Spaces and # inside quotes are characters; \n is one newline byte; \0 is NUL.
Placement exampleAt aligned B: one .word, then .space 14, then another .word places the last word at B+20 under ordinary MARS auto-alignment.
la r,label / lw r,labelGet the address / load the word at the label’s address. The latter is assembler shorthand.
lw/sw r,offset(base)Address = base + signed byte offset; access four bytes at a multiple of 4. A store copies from r into memory.
lb/lbu/sb; lh/lhu/shByte access: any valid byte address. Halfword access: a multiple of 2. Signed loads sign-extend; unsigned loads zero-extend; stores keep the low 8/16 bits.
Word array / byte stringElement i is at base+4i / base+i. Alignment and object bounds are separate requirements.
Little-endian / big-endian0x12345678 has increasing-address bytes 78 56 34 12 / 12 34 56 78. MARS uses little-endian; neither rule reverses character order.
String boundaryNUL=0; newline=10; character “0”=48. Service 8 reserves one capacity byte for NUL and may retain the input newline.
String algorithmsCompare string lengths after counting before NUL; trim a captured newline; swap inward to reverse; change only lowercase ASCII. All-vowel output preserves case/repetitions; the unique-vowel variant lowercases and removes repeats.
Memory map; alignment; signed/unsigned loads; buffer limits; reversal; length and vowels. A value spanning two words needs two ordinary loads; a large object is not automatically stored in HI/LO.

6. Leaf calls and register contracts
Write the argument, result, and changed-register contract before calling. A leaf calls no other function; the examples here use only temporary scratch registers and need no stack frame. Keep the numeric result separate from the address where execution returns.
Step / register familyRule
Arguments and resultPut the first four integer/pointer arguments in $a0–$a3; read the agreed result in $v0 (or a documented $v1 result).
jal labelRecord the next basic instruction’s address in $ra and transfer control. With delayed branching OFF, the return link is PC+4.
jr $raJump to the return address; the numeric answer is already in the result register.
Caller-visible changes$t0–$t9, $a0–$a3, and $v0–$v1 may change across a call; returning does not restore them automatically.
Preserved stateA function restores any $s register it changes and its incoming $sp; detailed saving belongs to the following lesson.
Printing a resultCopy $v0 to $a0 before loading service number 1 into $v0.
Program layoutEnd main with exit or a jump past procedure bodies. A label is not an automatic boundary.
Polynomial examplepolyval(x,a,b,c)=a*x*x+b*x+c; Horner form (a*x+b)*x+c gives the same in-range result.
jal leaf
move $a0,$v0       # preserve the answer as the print argument
li $v0,1

#include <iostream>

int minValue(int x, int y) {
    if (y < x)
        return y;
    return x;
}

int maxValue(int x, int y) {
    if (x < y)
        return y;
    return x;
}

int main() {
    int x, y;
    std::cin >> x >> y;
    int minimum = minValue(x, y);
    int maximum = maxValue(x, y);
    std::cout << minimum << ' ' << maximum << '\n';
    return 0;
}
Main copies the first result into $s0, which the second leaf leaves unchanged. It reloads the original arguments from $s1/$s2 before that call. Afterward, $t2 keeps the second result while MARS print services reuse $v0. The two calls are sequential: neither leaf calls another function or adjusts $sp.

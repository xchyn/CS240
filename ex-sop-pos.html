Exercise set 5 · after the SOP / POS lecture Canonical forms

From a truth table to a circuit, mechanically

Minterms and maxterms; reading a sum-of-products expression off the 1-rows of a table and a product-of-sums off the 0-rows; the Σ and Π shorthand; and the two-level circuits both forms turn into.

Set 4 asked you to make an expression smaller, which needs judgement. This set asks the opposite question and needs none: given a truth table — any truth table at all — write down an expression that produces it. There is a procedure, it never fails, and it answers the question Set 3 raised and left hanging. Every function you can specify, you can build; and you can build it in the same two-layer shape every time.

Two procedures, in fact, because you can work from the rows where the output is 1 or from the rows where it is 0. They give different-looking expressions for the same function, and knowing both is the difference between a full mark and half of one on the quiz.

5.1One row, one term

Everything rests on a single construction. Take one row of a truth table. There is exactly one product of all the variables that is 1 on that row and 0 on every other row: include each variable plain where the row has a 1, and complemented where the row has a 0. That product is the row's minterm.

For the row A = 1, B = 0, C = 1 the minterm is AB′C. Check it: substituting those values gives 1 · 1 · 1 = 1, and any other row changes at least one of the three factors to 0, which kills the product. A minterm is a detector for one row.

Dually, there is exactly one sum of all the variables that is 0 on that row and 1 everywhere else: include each variable complemented where the row has a 1, and plain where the row has a 0. That is the row's maxterm. For the same row it is A′ + B + C′, which is 0 + 0 + 0 = 0 there and 1 anywhere else.

The maxterm's polarities are backwards

Read that again, because it is the one thing in this set that is genuinely easy to get wrong: in a minterm a 1 in the row gives a plain variable, and in a maxterm a 1 in the row gives a complemented one. Maxterms are inverted minterms — Mi = (mi)′, which is De Morgan and nothing more — so every literal flips and the AND becomes an OR.

Row 5 of a three-variable table, ABC = 101, gives m5 = AB′C and M5 = A′ + B + C′.

Rows are numbered by reading the input columns as a binary number, most significant variable on the left, exactly as the rows are already ordered. So for three variables there are eight of each, and this is the whole table you need:

5.2Sum of products

Now the construction. The output should be 1 on some set of rows, and a minterm is a detector for one row, so: OR together the minterms of every row where the output is 1. The result is 1 on exactly those rows and 0 on all the others, which is the function. That expression is the canonical sum of products.

The output is 1 on rows 0, 3 and 5. Their minterms are A′B′C′, A′BC and AB′C, so

F = A′B′C′ + A′BC + AB′C

Three product terms, one per 1-row, and no thought required beyond copying polarities off the table. Spot-check row 5: the third term is 1·1·1 = 1 so F = 1 — and the other two terms are 0 there, which is the point of minterms. Spot-check row 1: all three terms are 0, so F = 0. The table agrees.

Two things follow immediately, and both are worth saying out loud. Every Boolean function whatsoever can be written this way, so AND, OR and NOT really are enough to build anything — that is the fact the gates lecture asserted and this is the proof. And the canonical form is unique: the table determines the set of 1-rows, the 1-rows determine the minterms, and there is no choice anywhere in the procedure.

Unique does not mean minimal. The canonical form is usually bigger than it needs to be, and shrinking it is Set 4's business — Exercise 5.10 takes a canonical four-term expression down to a single letter.

5.3Product of sums

The mirror-image construction works from the other rows. A maxterm is 0 on exactly one row, and an AND is 0 if any factor is 0, so: AND together the maxterms of every row where the output is 0. The result is 0 on exactly those rows and 1 on all the others — the same function again. That is the canonical product of sums.

For the running example the 0-rows are 1, 2, 4, 6 and 7, so

F = (A + B + C′)(A + B′ + C)(A′ + B + C)(A′ + B′ + C)(A′ + B′ + C′)

Five sum terms against the SOP's three product terms, for the same function. That is not a mistake: the two forms have as many terms as the table has 0s and 1s respectively, so whichever the table has fewer of gives the shorter expression. A function that is mostly 1s has a short POS and a long SOP.

Why it is worth learning both

Three reasons. The quiz asks for both. The shorter of the two is a better starting point for simplification, and you can tell which it will be by counting 1s in the table before you write anything. And POS matches the hardware directly in some technologies — a NOR-gate implementation falls out of POS the way a NAND implementation falls out of SOP, which is where the functional-completeness lecture is going.

5.4Σ and Π notation

Writing out five maxterms is tedious and error-prone, so both forms have a shorthand that lists the row numbers instead. The running example is

F = Σm(0, 3, 5) = ΠM(1, 2, 4, 6, 7)

Σ lists the rows where the output is 1; Π lists the rows where it is 0. So the two index sets are complementary: together they account for every row exactly once. Converting between the forms is therefore not algebra at all — it is writing down the numbers from 0 to 2n − 1 that the other list left out. Exercise 5.4 is nothing but that.

The notation is only meaningful with an ordering

Σm(0, 3, 5) is ambiguous until you say which variables, in which order. With variables A, B, C row 5 is AB′C; with the same variables listed as C, B, A row 5 would be a different product. Always write the variable list, in order, alongside the shorthand — F(A, B, C) = Σm(0, 3, 5) — and when a question gives you a bare index list, state the ordering you are assuming.

5.5Two-level circuits

Both canonical forms have the same shape, and that shape maps straight onto gates. An SOP expression is a layer of AND gates — one per product term, each as wide as the term is long — feeding a single OR gate as wide as there are terms:

This is called a two-level circuit, because every signal passes through exactly two gates on its way from input to output (three, counting the inverters that produce the complemented literals; those are drawn as a separate column in a real schematic and are left out here so the structure is visible). Two levels means the propagation delay is the same for every input, and it is the smallest number of levels any non-trivial function can be built in.

A POS expression is the same picture upside down: a layer of OR gates, one per sum term, feeding a single AND gate.

So the choice between SOP and POS is a choice between AND–OR and OR–AND, and between them you can implement any truth table in a fixed, predictable shape. That is the real content of this set. Exercises 5.7 and 5.8 ask you to draw and cost both for the same function.

5.6Reference

  • Row numbering. Read the input columns as binary, first variable most significant. Row i of an n-variable table is the binary expansion of i in n bits.
  • Minterm mi. Product of all n variables; complement the ones that are 0 in row i. It is 1 only on row i.
  • Maxterm Mi. Sum of all n variables; complement the ones that are 1 in row i. It is 0 only on row i. And Mi = (mi)′.
  • Canonical SOP. Σm over the 1-rows. AND–OR circuit.
  • Canonical POS. ΠM over the 0-rows. OR–AND circuit.
  • Complement. F′ swaps the two index sets: if F = Σm(S) then F′ = Σm(S̄) and F′ = ΠM(S).
  • Counting. n variables give 2n rows, so 2n minterms, and 22n distinct functions.

5.7Exercises

Where a question gives a bare index list, assume the variables are in the order written and the first is most significant. Every answer here can be checked against the table it came from, and you should.

Single terms

For the row A = 0, B = 1, C = 1, write the minterm and the maxterm, and give the row's number. Then verify that each does what it should on that row and on one other row.

The row reads 011 in binary, so it is row 3.

Minterm. A is 0 so it is complemented; B and C are 1 so they stay plain:

m3 = A′BC

On row 3: A′ = 1, B = 1, C = 1, so the product is 1. On row 7 (ABC = 111): A′ = 0, so the product is 0. As required.

Maxterm. Every polarity flips. A is 0 so it stays plain; B and C are 1 so they are complemented; and the AND becomes an OR:

M3 = A + B′ + C′

On row 3: 0 + 0 + 0 = 0. On row 7: 1 + 0 + 0 = 1. As required.

The two are complements of each other, which is the fastest way to write the second once you have the first: (A′BC)′ = A + B′ + C′ by De Morgan. If you find yourself unsure about maxterm polarities in the middle of an exam, write the minterm and complement it.

In the SOP form from Exercise 5.2, every one of the four product terms contains a literal that is 0 on row 100 — for instance A′B′C′ has A′ = 0 — so the sum is 0.

A three-variable function is F = Σm(1, 4, 5, 7). Write its Π form, and both expressions in full — without building a truth table.

The Π list is whatever the Σ list left out. With three variables the rows are 0 to 7, so the missing ones are 0, 2, 3 and 6:

F(A, B, C) = Σm(1, 4, 5, 7) = ΠM(0, 2, 3, 6)

Four indices in each list, eight in total, none repeated — which is the check that you have not dropped one.

The SOP, one minterm per index in the Σ list:

F = A′B′C + AB′C′ + AB′C + ABC

The POS, one maxterm per index in the Π list, remembering that the polarities invert:

F = (A + B + C)(A + B′ + C)(A + B′ + C′)(A′ + B′ + C)

Row 3, for instance, is 011; as a maxterm that is A + B′ + C′. Getting this wrong — writing A′ + B + C, the minterm's polarities — is the single most common error on this topic, and it produces an expression for an entirely different function.

Expression to canonical form

Expand F = A + B′C into canonical sum-of-products form over the variables A, B, C, and give the Σ shorthand.

Neither term mentions all three variables, and a canonical form requires that every product does. The fix is the complement law used as an expander: multiplying a term by (X + X′) changes nothing, and splits it into two terms that each mention X.

The term A is missing B and C, so expand twice:

A = A(B + B′)(C + C′) = ABC + ABC′ + AB′C + AB′C′

which is m7, m6, m5, m4.

The term B′C is missing A:

B′C = (A + A′)B′C = AB′C + A′B′C

which is m5 and m1.

Collect, and drop the repeat — m5 appeared in both, and X + X = X:

F = A′B′C + AB′C′ + AB′C + ABC′ + ABC

F(A, B, C) = Σm(1, 4, 5, 6, 7)

Sanity check without a table: A alone should contribute all four rows with A = 1, which is 4, 5, 6, 7 — and it did. B′C adds the rows with B = 0, C = 1, which are 1 and 5, one of them new. Five minterms, so the table has five 1s and three 0s, and the POS form would be the shorter of the two.

The overlap is worth a comment. Terms of a non-canonical SOP can cover the same row twice; minterms of a canonical SOP never can. That is exactly why the canonical form is unique and an ordinary SOP is not.

Expand G = (A′ + B)(B + C′) into canonical product-of-sums form, and give the Π shorthand.

The dual method. A canonical POS needs every sum term to mention all three variables, and the expander is the other complement law: adding XX′ = 0 to a sum changes nothing, and the surprising distributive law splits the term in two.

The factor A′ + B is missing C:

A′ + B = A′ + B + CC′ = (A′ + B + C)(A′ + B + C′)

which is M4 and M5.

The factor B + C′ is missing A:

B + C′ = B + C′ + AA′ = (A + B + C′)(A′ + B + C′)

which is M1 and M5.

Collect the four factors and drop the duplicate M5, since X · X = X:

G = (A + B + C′)(A′ + B + C)(A′ + B + C′)

G(A, B, C) = ΠM(1, 4, 5)

Three maxterms, so G is 0 on three rows and 1 on the other five, and G = Σm(0, 2, 3, 6, 7).

The step that looks illegal is adding CC′ to a sum. It is the exact dual of multiplying by (C + C′): one adds a 0, the other multiplies by a 1, and neither changes the value. Then X + YZ = (X + Y)(X + Z) does the splitting. If this ever feels shaky, expand to SOP instead, find the 1-rows, and read the POS off the 0-rows — slower, and impossible to get wrong.

Circuits

Draw the two-level AND–OR circuit for F = Σm(0, 3, 5) over A, B, C. Count the gates and the total number of gate inputs, including the inverters.

Three minterms, so three AND gates, each with three inputs, feeding one three-input OR gate. The complemented literals come from three inverters on the input column.

The count. Three inverters, three 3-input ANDs and one 3-input OR — seven gates. Gate inputs: 3×1 for the inverters, 3×3 for the ANDs and 3 for the OR, so 15 inputs in total.

Gate inputs are the honest measure of cost, not gate count: a 3-input AND is physically bigger than a 2-input one, and a count that ignores that will tell you two very different circuits are equally cheap. If your ANDs and ORs are restricted to two inputs each, every 3-input gate becomes two 2-input gates, and the totals become 11 gates and 19 inputs — worth doing once so the restriction never surprises you.

Note which literals each AND gate needs: exactly the polarities of its row. Row 0 is 000, so its gate takes A′, B′, C′; row 5 is 101, so its gate takes A, B′, C. Reading the polarities off the row number is the whole skill, and it never involves thinking about the function as a whole.

Draw the two-level OR–AND circuit for F = ΠM(1, 6) over A, B, C, and compare its cost with the SOP circuit for the same function.

Two maxterms, so two three-input OR gates feeding one two-input AND gate.

The count. Three inverters, two 3-input ORs and one 2-input AND — six gates, and 3 + 6 + 2 = 11 gate inputs.

The comparison. ΠM(1, 6) means the function is 0 on two rows and 1 on the other six, so its SOP form has six minterms: six 3-input AND gates and a 6-input OR. That is 3 + 6 + 1 = 10 gates and 3 + 18 + 6 = 27 gate inputs, against 6 gates and 11 inputs for the POS. The POS is dramatically cheaper here.

The rule this illustrates: count the 1s and the 0s in the table first. Whichever is scarcer names the form you should be building. A function that is mostly 1s wants POS; a function that is mostly 0s wants SOP; and a function that is evenly split makes the choice on other grounds, such as which gate type your technology prefers.

Both counts are before any simplification. Reducing either form with the algebra of Set 4 usually changes the answer to which one wins, which is why the count above is a starting heuristic and not a conclusion.

In words: a BCD digit is illegal exactly when the top bit is set and either of the next two is. Read against the binary, that is obvious — anything from 1010 upward has W set and needs at least one of X or Y to exceed 1001. Z never matters, which the simplified expression says by omitting it.

This circuit is real. It is what a BCD-to-seven-segment decoder uses to blank the display on an invalid code, and the same detector, with its output fed back as a correction term, is the core of the BCD adder's "add 6" fix-up.

What it means. The canonical SOP is the minimal SOP: four 3-input AND gates and a 4-input OR, and no algebra will reduce it. Parity is the standard example of a function that two-level minimisation cannot help, and on a Karnaugh map its 1s appear as a checkerboard with no two adjacent — the visual form of the same argument.

Which is the case for the gate. Built from XORs the function is two gates; built as a minimal SOP it is five gates and 16 gate inputs. That gap, not novelty, is why XOR was given a symbol of its own — and it is also why a minimal two-level circuit is not always a minimal circuit. Allowing more levels, XOR wins easily.

Convert F = (A + B′)(A′ + C) to sum-of-products form, simplify it, and give the canonical Σ form.

Multiply out, taking each term of the first factor against each of the second:

(A + B′)(A′ + C) = AA′ + AC + A′B′ + B′C

The first product dies by the complement law, leaving three terms:

F = AC + A′B′ + B′C

Now look at the shape. A appears in both polarities in the first two terms, and the third is made of exactly the leftovers, C and B′ — the consensus pattern from Exercise 4.12. So B′C is redundant:

F = AC + A′B′

The canonical form. Expand each term to mention all three variables. AC is missing B, so AC = ABC + AB′C, which is m7 and m5. A′B′ is missing C, so A′B′ = A′B′C + A′B′C′, which is m1 and m0.

F(A, B, C) = Σm(0, 1, 5, 7) = A′B′C′ + A′B′C + AB′C + ABC

Check the discarded term against this: B′C expands to A′B′C + AB′C, which is m1 and m5 — both already in the list. That is what redundancy looks like at the level of minterms, and it is a good way to confirm a consensus step you are not sure about.

Four minterms out of eight, so the POS form has four maxterms too and neither is obviously the cheaper route. The simplified SOP, at two terms, beats both.

Counting

Challenge. How many distinct Boolean functions of three variables are there? How many of them have exactly three minterms? And explain why every function has exactly one canonical SOP, when it has many ordinary SOPs.

How many functions. A three-variable function is completely determined by its output column, which is 8 bits long, and every one of the 28 possible columns is a legitimate function. So there are 256. In general n variables give 2n rows and

22n functions

which grows appallingly fast: 16 functions of two variables, 256 of three, 65,536 of four, and about 1.8 × 1019 of six. Any thought of tabulating all circuits of six inputs to find the best one dies right there, which is why minimisation needs technique rather than search.

How many with exactly three minterms. Choosing a function with three minterms is choosing which 3 of the 8 rows are the 1-rows:

C(8, 3) = 8! / (3! · 5!) = 56

And as a check on the first answer, summing over every possible number of minterms gives C(8,0) + C(8,1) + … + C(8,8) = 28 = 256, which is the binomial identity and the same count arrived at a second way.

Why the canonical form is unique. Two directions.

It exists and is determined by the function. The procedure of §5.2 reads the set of 1-rows off the table and writes one minterm for each. Nothing in that involves a choice, so the function fixes the expression.

No other canonical SOP gives the same function. Suppose two different sets of minterms were ORed to give the same function. The sets differ, so some mi is in one and not the other. On row i, mi is 1 and every other minterm is 0 — that is the defining property. So the first expression is 1 on row i and the second is 0, and they are not the same function after all. Contradiction.

The reason ordinary SOPs are not unique is that their terms are not minterms and so do not have that one-row property. AB′ is 1 on two rows, A on four, and terms like these can overlap, so a row can be covered once, twice, or in several different ways — and each way of covering it is a different expression for the same function. Exercise 5.5 saw one overlap directly. Uniqueness is bought precisely by insisting every term name every variable.

A useful consequence

Because canonical forms are unique, they settle equality questions outright: two expressions denote the same function if and only if their canonical forms are identical. That is a decision procedure — expand both, compare the index lists, done — and it is what you fall back on when an algebraic manipulation is disputed and neither side can find the error.

Where this goes next

Two loose ends, and the next two lectures are each one of them. The canonical form is mechanical but wasteful, and simplifying it by algebra means spotting patterns in a list of terms — a Karnaugh map redraws the table so that combinable terms sit next to each other and the patterns become shapes. And the two-level circuits here need AND, OR and NOT, where real chips are built from one repeated gate; the universality lecture shows that NAND alone suffices, with the SOP form of this set as its starting point.

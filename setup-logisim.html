Installing Logisim-Evolution

Logisim-Evolution is the circuit simulator we use for the whole logic-design half of the course. It is free, it runs on everything, and it takes about five minutes to install — four of which are spent convincing your operating system to trust it.

A.1Which program

Search the web for "Logisim" and you will find two different programs. Get the right one.

Logisim (original)Logisim-Evolution
authorCarl Burcha community fork, on GitHub
statusdiscontinued in 2014actively maintained
use in this coursenoyes

The original Logisim is what most tutorials and older course pages point at. It still runs, but it has not been updated in over a decade, it does not always start on current versions of macOS, and the .circ files distributed for this course use features it does not have. Install Logisim-Evolution. A file saved by the original will open in Evolution; the reverse is not guaranteed.

A.2Getting the file

Every download lives in one place, the project's GitHub releases page:

github.com/logisim-evolution/logisim-evolution/releases/latest

Scroll to the Assets section of the newest release and expand it. You will see roughly nine files. Exactly one of them is yours; the table below says which. At the start of this semester the current release is 4.1.0, published 15 February 2026, and the filenames below use that version number — if you find a newer release, take it, and read 4.1.0 as whatever version you are downloading.

your machinefile to download
Mac, Apple silicon (M1…M4)logisim-evolution-4.1.0-aarch64.dmg
Mac, Intellogisim-evolution-4.1.0-x86_64.dmg
Windows, Intel or AMDlogisim-evolution-4.1.0-amd64.msi
Windows on ARMlogisim-evolution-4.1.0-aarch64.msi
Debian, Ubuntu, Mintlogisim-evolution_4.1.0-1_amd64.deb
Fedora, RHEL, CentOSlogisim-evolution-4.1.0-1.x86_64.rpm

You do not need to install Java

Every platform installer above ships with its own copy of Java inside it. You only need a separate Java installation if you take the .jar route in §A.6, and that route needs Java 21 or newer.

A.3macOS

Which chip do you have?

Apple menu → About This Mac. If the line says Chip: Apple M1 (or M2, M3, M4) take the aarch64 file. If it says Processor: Intel, take x86_64. If you are not sure, the x86_64 build runs on both — Apple silicon translates it through Rosetta — it is just slower.

Install

  1. Download the .dmg and double-click it. A window opens with the Logisim-Evolution application in it.
  2. Drag the application into your Applications folder.
  3. Eject the disk image (the small ⏢ beside it in the Finder sidebar).

First launch — this is the part that trips people up

macOS will refuse the first time

Logisim-Evolution is not code-signed by an Apple developer account, so a plain double-click produces something like "Logisim-Evolution cannot be opened because the developer cannot be verified". This is expected and it does not mean the file is broken.

Do this instead: open your Applications folder, hold Control and click (or right-click) the Logisim-Evolution icon, choose Open from the menu, and then click Open in the dialog that appears. The dialog now has an Open button that the double-click version did not.

If that still fails on a recent macOS: go to System Settings → Privacy & Security, scroll down to the Security section, find the line saying Logisim-Evolution was blocked, and click Open Anyway. Then launch it again.

You only do this once. Every launch after the first is an ordinary double-click.

A.4Windows

Which build?

Almost certainly amd64. Take aarch64 only if you have an ARM machine — a Snapdragon-based Surface or Copilot+ PC. To check: Settings → System → About, and read the System type line.

Install

  1. Download the .msi and double-click it.
  2. Windows SmartScreen will very likely say "Windows protected your PC", because the installer is not signed with a commercial certificate. Click More info, then Run anyway. There is no other button that will work; the dialog deliberately hides it behind that link.
  3. Accept the defaults through the installer. It will offer to create a Start menu entry and a desktop shortcut — take both, they make it easier to find later.
  4. Launch it from the Start menu.
If your browser blocks the download

Edge and Chrome sometimes flag an .msi from GitHub as "not commonly downloaded". In the downloads list, click the … beside the file and choose Keep, then Keep anyway.

A.5Linux

Download the package for your distribution and install it from the terminal, in the folder you downloaded it to. The leading ./ matters: it tells the package manager to install a local file rather than search for that name in the repositories.

# Debian, Ubuntu, Mint
sudo apt install ./logisim-evolution_4.1.0-1_amd64.deb

# Fedora, RHEL, CentOS
sudo dnf install ./logisim-evolution-4.1.0-1.x86_64.rpm

# snap-based systems
sudo snap install --dangerous logisim-evolution-4.1.0_amd64.snap

Java comes bundled in all three packages. The --dangerous flag on the snap is only there because the file is a local snap rather than one from the Snap Store; it is not a warning about the program. After installation, Logisim-Evolution appears in your applications menu, or runs from the terminal as logisim-evolution.

A.6Anything else — the .jar

Use this route if you are on a platform with no installer, or on a machine where you cannot install software (a lab computer, a locked-down laptop). The .jar is a single file that runs from wherever you put it, including a USB stick.

  1. Get Java 21 or newer. Check what you have by opening a terminal or Command Prompt and running java -version. If the number is below 21, or the command is not found, download a JDK from adoptium.net/temurin/releases — pick the Temurin JDK for your operating system, version 21 or later.
  2. Download the .jar from the same Assets list on the release page.
  3. Run it from the folder it is in: 
    java -jar logisim-evolution-4.1.0-all.jar
    The exact filename is whatever the release page shows; copy it rather than typing it from here.
Chromebooks

A Chromebook needs the Linux development environment turned on (Settings → About ChromeOS → Developers → Linux) before any of this works. Once it is on, treat the machine as Debian and use either the .deb from §A.5 or the .jar above.

A.7Check it works

Do this now, not five minutes before the first circuit is due. Two minutes:

  1. Launch Logisim-Evolution. You should get a blank canvas with a toolbar across the top and a component tree down the left.
  2. In the tree, open Gates and click AND Gate. Click once on the canvas to place it.
  3. Open Wiring, click Pin, and place two pins to the left of the gate. Place a third pin to the right of it and, in the properties panel at the bottom left, set its Output? property to Yes.
  4. Choose the arrow tool and drag from each pin to the matching gate terminal to wire them up.
  5. Choose the poke tool — the pointing hand — and click the input pins to flip them between 0 and 1. The output pin should turn green (1) only when both inputs are 1.

If the output responds, your installation is good. Save the file somewhere you can find it; you will be opening and editing .circ files all semester.

Opening a course circuit

Circuit files handed out for the course are ordinary .circ files. Download one, then use File → Open inside Logisim-Evolution rather than double-clicking it in your file manager — on most systems .circ is not associated with anything, and double-clicking opens a text editor showing raw XML.

A.8Troubleshooting

Nothing happens when I double-click the app on macOS. No error, no window.

Almost always the unsigned-app block described in §A.3, failing silently. Control-click the app in Applications and choose Open, or go to System Settings → Privacy & Security and click Open Anyway next to the message about Logisim-Evolution.

If that is not it, you may have downloaded the wrong architecture. An aarch64 build will not run on an Intel Mac at all. Check About This Mac and download the other one.

Windows says the publisher is unknown, or the file is unsafe.

Expected: the installer is not signed with a commercial code-signing certificate, which costs money the volunteer project does not spend. Click More info → Run anyway on the SmartScreen dialog, and Keep → Keep anyway in the browser's download list if it objected too.

Download only from the GitHub releases page linked in §A.2. Sites offering "Logisim download" with their own installer are wrapping it in something you do not want.

I get "Unsupported class file major version" or "UnsupportedClassVersionError" when running the .jar.

Your Java is too old. Logisim-Evolution 4.x needs Java 21 or newer. Run java -version and check the number. If you have several versions installed, the one on your PATH is the one being used — install Temurin 21 from adoptium.net and make sure it comes first, or give the full path to its java executable.

The text and icons are microscopic (or enormous) on a high-resolution display.

There is a scaling setting inside the program: File → Preferences → Window, and adjust the zoom or scale factor there. Restart the program afterwards if the change does not take effect immediately.

A .circ file opens as pages of XML instead of a circuit.

Your operating system opened it in a text editor because nothing is registered for the .circ extension. That is harmless — the file really is XML. Open Logisim-Evolution first and use File → Open from inside it.

If you want double-clicking to work: on Windows, right-click the file → Open with → Choose another app → Logisim-Evolution → Always. On macOS, Get Info → Open with → Logisim-Evolution → Change All.

My university or work laptop will not let me install anything.

Use the .jar route in §A.6. Both the JDK and the jar can live in your own home folder or on a USB stick, and neither needs administrator rights on most managed machines. If java is blocked entirely, come and see me — there are lab machines with it installed.
